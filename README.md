# CDL System — sajt (cdlsystem.com)

Statički sajt (HTML/CSS/JS, bez build-a) koji se hostuje na Vercelu iz GitHub-a.

## Brzi start
```bash
npm run dev     # lokalni pregled na http://localhost:3000
npm run check   # provera linkova/SEO osnova (mora biti 0 problema)
```

## Gde je šta
| Folder / fajl | Sadržaj |
|---|---|
| `public/` | ceo sajt (ovo se deploy-uje) |
| `design/` | dizajn plan (bol-design), copy, struktura sajta, specifikacija animacije, GIF referenca |
| `research/` | istraživanje tržišta/konkurencije, SEO/GEO strategija, ideje |
| `docs/` | arhitektura, analiza postojećeg sajta, odluke, deploy, **HANDOFF** |
| `CLAUDE.md` | uputstvo za sledećeg AI agenta (čita se prvo) |

## Status
Postavka projekta, istraživanje, dizajn plan i copy su gotovi. **Kod sajta još nije prepravljen** na novi (svetli/crveni) dizajn — vidi `docs/HANDOFF.md`.
Repo nije pushovan na GitHub (token u okruženju nije važeći) — vidi `docs/DEPLOYMENT.md`.
